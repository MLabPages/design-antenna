フィッツの法則

Fitts's Law

01どういう知識か

1954年、心理学者のポール・フィッツは、2つの的のあいだをペンで交互にすばやくたたく実験などから、狙って手を動かすのにかかる時間が「的までの距離」と「的の大きさ」で決まることを示しました。画面の操作の研究（HCI）では、MacKenzie（1992）がまとめた次の形がよく使われます。

MT = a + b · log₂(D / W + 1)

D は的までの距離、W は動かす向きに測った的の幅、a と b は人や機器（マウス、指など）で決まる定数です。log₂(D / W + 1) は「難しさの指数（ID）」と呼ばれ、単位はビットです。

ポイントは、時間が D と W の「比」で決まることです。的を近づけるか、的を大きくすると、速く、押しまちがいも少なくなります。距離が同じなら、幅を2倍にすると難しさはおよそ1ビット下がります。

ウェブでは、WCAG 2.2 が押せる範囲の目安を示しています。24×24 CSS px 以上がレベルAA（2.5.8。小さくても周りに十分な間隔があれば例外）、44×44 CSS px 以上がレベルAAA（2.5.5）です。

02具体例

悪い例：研究サイトの論文一覧で「PDF・スライド・コード」を、小さな文字リンクのまま詰めて並べます。押せる範囲は高さ28pxほど、隣とのすき間は10pxほどです。カーソルから600px先なら、難しさは log₂(600/28 + 1) ≈ 4.5ビット。スマホでは隣のリンクを押してしまいがちです。

良い例：同じ3つを高さ56pxのボタンにして、20pxずつ間をあけます。難しさは log₂(600/56 + 1) ≈ 3.6ビットに下がり、指でもマウスでも一度で押せます。よく使う操作（「次へ」「送信」など）を、目と手が向かう場所の近くに置けば、D も小さくなります。

03今日から使えるひとこと

自分の研究サイトをスマホで開き、論文のPDFリンクやメニューを親指で押してみてください。押しにくければ、CSS の padding で押せる範囲を高さ44px以上に広げ、隣とのすき間もあけましょう。文字の大きさはそのままでも、押せる範囲だけを広げられます。フォームやアンケート画面でも、よく使うボタンは「大きく、近くに」です。
