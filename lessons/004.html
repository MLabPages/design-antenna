行の長さ

Line Length (Measure)

01どういう知識か

タイポグラフィでは、1行の長さを行長（メジャー）と呼びます。タイポグラファーのロバート・ブリングハーストは『The Elements of Typographic Style』で、欧文の1段組なら1行45〜75字が満足できる長さで、66字が理想とされると書いています。

Webアクセシビリティの基準 WCAG 2.2 の達成基準1.4.8（レベルAAA）も、文章のかたまりの幅を80字以内、日本語などのCJKでは40字以内にできることを求めています。あわせて、段落内の行間は1.5倍以上です。

W3Cの解説によると、長い行は読む位置を見失いやすく、次の行へ移るのが難しくなります。幅の狭い段落のほうが、次の行へ目を運びやすいのです。

02具体例

悪い例：横長の画面いっぱいに本文を流し込み、1行約60字・行間も詰まった状態。行末から次の行頭へ戻るたびに、どの行を読んでいたか迷います。

良い例：同じ文章を1行約32字の段に収め、行間を約1.8倍に広げます。行数は増えても目の戻りが楽で、最後まで読み通せます。空いた横のスペースには、要点や図を置けます。

03今日から使えるひとこと

研究サイトなら、本文の段落に CSS で `max-width: 40em;` と `line-height: 1.8;` を指定してみてください。日本語の全角1文字はほぼ1emなので、1行が約40字に収まります。スライドでは、説明文のテキストボックスを横幅いっぱいに広げず、半分ほどの幅にして図と並べましょう。

  2. Understanding SC 1.4.8: Visual Presentation (Level AAA) W3C WAI（WCAG 2.2） https://www.w3.org/WAI/WCAG22/Understanding/visual-presentation.html
